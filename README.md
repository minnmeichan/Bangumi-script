# Bangumi-script

个人编写的有关 Bangumi 的脚本

## 脚本列表

### 1. 收藏人物框样式改 5×2

功能：
- 修改 Bangumi 用户页面"我收藏的人物"框的显示布局
- 调整为 5×2 布局，不满 5 个时合并为一行
- 将原来的图片对名字进行居中处理，和"我的朋友"框的样式一样
- 只对收藏人物框在右边栏的有效，如果在左边栏不生效  
  （左边栏也用不到我这个组件，不过如果你非常喜欢视奸别人的时光机你也可以装上看看）

支持网站：
- bgm.tv
- bangumi.tv
- chii.in
- bangumi.vip

安装：
[安装 收藏人物样式改 5×2](https://github.com/minnmeichan/Bangumi-script/raw/refs/heads/main/favorite-person-style.user.js)

### 2. Bangumi 封面上传与切换增强版（改）

基于 Bios 的脚本修改。增强 Bangumi 的封面上传与切换功能，支持 URL 上传、本地上传、封面切换及透明投票按钮，多通道下载，自带暗黑模式。

功能：
- 在导航栏添加上传封面按钮，支持 URL 与本地两种上传方式
- 自动压缩、转换图片格式（透明保留 PNG，否则 JPEG 并逐级降质）
- 上传后自动投票，页面 3 秒后刷新
- 封面切换箭头 + 投票按钮
- 多通道下载，国内无梯子也能下载图片
- 角色页自动对齐 luoli commons 的评分按钮
- 暗黑模式跟随 Bangumi 主题设置

支持网站：
- bgm.tv
- bangumi.tv
- chii.in

安装：
[安装 Bangumi 封面上传与切换增强版（改）](https://raw.githubusercontent.com/minnmeichan/Bangumi-script/refs/heads/main/bangumi_cover_plus.user.js)

完整更新日志见 [CHANGELOG-bangumi-cover-plus.md](./CHANGELOG-bangumi-cover-plus.md)
